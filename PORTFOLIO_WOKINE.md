# Projet sélectionné — CUB

## Application web métier PHP / MySQL

**Contexte**  
CUB est une application web de suivi de production conçue autour de besoins opérationnels : commandes, dossiers de fabrication, clients, réceptions, tickets et paramètres métier.

**Mon travail**  
J’ai travaillé sur la logique PHP, les échanges avec MySQL/MariaDB, les formulaires et tableaux de suivi, les filtres de recherche ainsi que des mises à jour dynamiques en AJAX. Le projet m’a demandé de comprendre une logique métier existante, de naviguer dans une base de code et de résoudre des problèmes de manière autonome.

**Technologies**  
PHP · MySQL/MariaDB · PDO · HTML/CSS · JavaScript · jQuery · AJAX · Bootstrap · WAMP

**Fonctionnalités visibles dans le code**  
Planning de production filtrable, dossiers de fabrication, gestion des réceptions, historique, tickets, paramètres métier et gestion de session.

**Ce que j’en retiens**  
Ce projet m’a donné une expérience concrète d’une application fullstack orientée métier. Il m’a aussi permis d’identifier des améliorations professionnelles à apporter : sécurisation des requêtes SQL, gestion moderne des mots de passe, configuration par environnement, structuration du code, tests, API REST, Docker et CI/CD.
